# Task 03 — Choose Variables and Name the Constants

Use UPPER_CASE for constants and snake_case for variables/functions. Python does not enforce constants; uppercase is a convention. A variable can refer to values of different types because Python is dynamically typed, but changing types without a reason can make code harder to understand.

Rate revisions should be made in one rate-card definition rather than changing repeated magic numbers. The dictionary alternative is included in `constants_demo.py`.
