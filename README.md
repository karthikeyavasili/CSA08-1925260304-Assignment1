This repository starter is organised into Task01–Task12 folders based on the assignment brief, “Design, Implement and Validate a Payment Calculator for a Village Milk Co-operative.”

## Folder contents
Each task folder includes a task-specific README, relevant Python source files, and an `evidence/` folder for your own execution screenshots. Task 8 includes a Mermaid flowchart and hand-trace CSV.

## Requirements
- Python 3.10+ recommended
- Standard library only (`decimal`, `dataclasses`, `math`, `time`, `unittest`)
- No external packages required

## Run examples
From the repository root:
- `python Task02/types_demo.py`
- `python Task07/milkrate.py`
- `python Task07/test_milkrate.py`
- `python Task09/milk_calculator.py`
- `python -m unittest discover -s Task09 -p "test_*.py" -v`
- `python Task10/benchmark_totals.py`
- `python Task12/seasonal_calculator.py`
