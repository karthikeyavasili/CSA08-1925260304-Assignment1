# Task 02 — Explore Values and Types in the Interpreter

Run `python types_demo.py` and save a screenshot of your own output in `evidence/`.

Key points:
- `10` is `int`; `10.0` is `float`; `"10"` is `str`; `True` is `bool`; `[10, 8.5]` is `list`.
- `/` performs true division; `//` floors; `%` returns the remainder.
- `0.1 + 0.2 == 0.3` is false because binary floats cannot represent these decimal fractions exactly.
- Decimal values should be created from strings, e.g. `Decimal("0.1")`.
